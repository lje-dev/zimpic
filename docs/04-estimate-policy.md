# 04. 견적 산출 정책

> 서비스의 핵심 로직이다. 포장 후 짐의 크기와 적재 가능 여부로 차량을 정하고, 합계 톤수와 이동 조건으로 예상금액을 계산한다.

## 1. 견적 산출 흐름

| 단계 | 산출 기준 |
| --- | --- |
| 1 | 평수 구간의 평균 박스 수 산출 |
| 2 | 가구와 박스에 포장재 두께를 적용해 포장 후 W/D/H 계산 → [05. 가구 데이터](05-furniture-data.md) |
| 3 | 포장 후 부피를 합산해 차량 후보를 1차 선별 |
| 4 | 작은 차량부터 회전·충돌·적층 조건을 적용한 3D 적재 수행 |
| 5 | 모든 짐의 배치에 성공한 최초 차량 또는 차량 조합 확정 |
| 6 | 합계 톤수와 이동 조건을 반영하여 단일 예상금액 계산 |

## 2. 견적 산출식

**예상 견적 = ① 기본요금 + ② 출발지 접근비용 + ③ 도착지 접근비용 + ④ 거리 비용 + ⑤ 특수 가구 비용**

- **일반 이사**: 고객이 포장과 정리를 담당하며, 업체는 차량 운전·운반과 도착지의 지정 위치 배치만 제공한다.
- **포장 이사**: 업체가 이삿짐 포장부터 운반, 도착지 배치와 정리까지 제공한다.

| No | 항목 | 기준 | 응답 key |
| --- | --- | --- | --- |
| ① | 기본요금 | 차량 합계 톤수 + 이사 종류 | `BASE` |
| ② | 출발지 접근비용 | 층수 · 엘리베이터 · 사다리차 여부 | `LADDER` / `STAIRS` (scope `ORIGIN`) |
| ③ | 도착지 접근비용 | 층수 · 엘리베이터 · 사다리차 여부 | `LADDER` / `STAIRS` (scope `DEST`) |
| ④ | 거리 비용 | 기본 거리 초과분 | `DISTANCE` |
| ⑤ | 특수 가구 비용 | 분해 / 조립 / 설치 옵션 | `SPECIAL` |

- 결과는 확정 금액이 아닌 단일 예상금액으로 제공한다.
- 주말·성수기·손 없는 날과 실제 현장 조건은 자동 계산하지 않으며 추가금 발생 가능성을 안내한다.
- 분해·조립 서비스는 특수 가구 비용에만 반영하고 차량 산정용 치수와 부피는 변경하지 않는다. 단, 설치 상태로 운반하지 않는 시스템 행거는 블록별 분해 포장 크기를 기본 적재 치수로 사용한다.
- 도착지 미정 시 이동 거리를 계산하지 않고 거리 비용과 도착지 접근비용을 제외한 최소 예상금액을 제공한다.
- 도착지가 입력되면 출발지부터 도착지까지의 실제 산출 거리를 기준으로 거리 추가요금을 계산한다.
- 도착지가 입력됐지만 거리를 산출할 수 없으면 도착지 미정과 구분하여, 거리 비용을 0원으로 확정하지 않고 견적 계산 불가를 안내한다.

### 접근 비용

| 조건 | 적용 |
| --- | --- |
| 엘리베이터 가능 | 접근 비용 없음 |
| 엘리베이터 불가 + 사다리차 가능 | 사다리차 비용 |
| 엘리베이터·사다리차 모두 불가 | 계단 비용 |

사다리차 요금은 차량이 여러 대이더라도 가장 큰 차량 한 대가 아니라 **차량 구성의 합계 톤수 등급**을 기준으로 적용한다. 계단 요금은 차량 톤수와 관계없이 층수만으로 계산한다.

## 3. 차량 선정과 3D 적재

### 차량 후보와 선택

차량 후보는 다음 순서로 검사한다.

`1T` → `2.5T` → `5T` → `5T+1T` → `5T+2.5T` → `5T×2` → `10T 초과 조합`

1. 포장 후 전체 CBM이 차량 정책 용량 이하인지 확인한다.
2. 각 물건에 허용된 회전과 적층 조건을 적용해 차량 내부에 3D로 배치한다.
3. 모든 물건이 경계를 벗어나거나 서로 겹치지 않고 배치되면 해당 차량 조합을 선택한다.
4. 배치에 실패하면 다음 차량 조합으로 다시 시도한다.

CBM은 차량 후보를 빠르게 거르고 적재율을 표시하는 보조 지표다. 최종 차량은 총 CBM만으로 결정하지 않고, 차량 내부 W/D/H에 모든 짐을 실제로 배치할 수 있는지를 기준으로 결정한다.

### 다중 차량과 요금 등급

| 차량 구성 | 합계 톤수 요금 등급 |
| --- | --- |
| 5T + 1T | 6T |
| 5T + 2.5T | 7.5T |
| 5T + 5T | 10T |

기본요금과 사다리차처럼 톤수에 연동되는 요금에는 같은 합계 톤수 등급을 사용한다. 계단 요금에는 톤수 등급을 적용하지 않는다. 10톤을 초과하면 10톤 기준 예상금액을 표시하고, 정확한 차량 구성과 금액은 전화상담으로 결정한다.

일반 이사는 차량 합계가 5톤 미만일 때만 제공한다. 사용자가 일반 이사를 선택했더라도 산정 물량이 5톤 이상이면 포장이사로 자동 전환하고 해당 톤수의 포장이사 기본요금을 적용하며, 전환 사유를 결과 화면에 안내한다.

### 3D 적재 결과

추천 차량 산정과 화면 표시는 하나의 배치 결과를 공유한다. 각 적재 항목에는 다음 정보가 포함된다.

```json
{
  "truck_index": 0,
  "item_id": "uuid",
  "position_cm": { "x": 0, "y": 0, "z": 0 },
  "packed_size_cm": { "w": 107, "d": 52, "h": 77 },
  "orientation_code": "WDH",
  "stacked_on_item_id": null
}
```

- `truck_index`: 여러 차량 중 배치된 차량 번호
- `position_cm`: 차량 내부 원점을 기준으로 한 적재 위치
- `packed_size_cm`: padding과 회전을 적용한 최종 배치 크기
- `orientation_code`: 적용한 회전 방향
- `stacked_on_item_id`: 다른 물건 위에 적층한 경우 아래 물건 ID

3D 화면은 이 좌표와 회전 결과를 그대로 사용하며 별도의 적재 계산을 하지 않는다.

박스 기준: 이사 박스 5호 40×60×45cm = **0.108 CBM**. 박스도 가구처럼 개별 적재 아이템으로 트럭 플랜에 넣는다.

- 최소~최대 개수는 짐량에 따른 변동 가능성을 보여주는 참고 범위로만 표시한다.
- 최소·최대 개수로 차량이나 금액을 다시 계산하지 않는다.

### 거리 비용 (`distance_fee_rule.csv`)

기본 20km까지는 추가요금이 없고, 20km 초과분은 10km 단위로 올림하여 추가한다.

`거리 추가요금 = ceil((산출 거리 - 20km) ÷ 10km) × 톤수별 단가`

| 트럭 | 10km당 |
| --- | --- |
| 1T | 20,000 |
| 2.5T | 25,000 |
| 5T / 6T | 30,000 |
| 7.5T | 40,000 |
| 10T | 50,000 |

- 도착지 미정: 거리 계산을 생략하고 거리 추가요금은 0원으로 한다.
- 도착지 입력: 실제 산출 거리에 위 계산식을 적용한다.
- 10톤 초과: 사용자에게 표시하는 10톤 기준 예상금액에 10톤 거리 단가를 적용하고, 최종 금액은 전화상담으로 확정한다.

### 사다리차 비용 (`ladder_fee_rule.csv`)

## 5. 기본요금 산출 근거

출처: 한국소비자원, **2021 소비자시장평가지표 활용 연구: 포장이사서비스 시장을 중심으로** — 제2장 제2절 2. 우리나라 포장이사서비스 시장 현황 > 평균요금, <표 2-9> 포장이사 비용
<https://www.kca.go.kr/smartconsumer/synapviewer.do?menukey=7301&fno=10033165&bid=00000146&did=1003275421>

### 1) 기준 통계

<표 2-9>는 **25km 이내 운송, 작업원 8시간, 1회 포장이사** 조건에서 운송비·인건비·기타비용을 합한 평균 비용이다. 비용 구성은 운송비 약 30%, 인건비 약 60%다.

| 톤수 | 2017 | 2020 | 상승률 |
| --- | --- | --- | --- |
| 5톤 | 72.8만 | 81.5만 | 약 +12% |
| 6톤 | 85.2만 | 94.9만 | 약 +11% |
| 7톤 | 107.2만 | 120.9만 | 약 +13% |

### 2) 2026년 환산

2017~2020 상승 추세(3년 누적 11~13%)가 이어진다고 가정해 2020 평균을 2026년 기준으로 보수적으로 환산했다. 외부 시세는 반영하지 않았다.

이어서 인건비 비중(약 60%)이 큰 서비스라 최저임금 상승을 현실 보정으로 더했다. 최저임금은 2021년 약 8,700원에서 2026년 약 10,300원으로 **누적 약 18~20%** 올랐다.

| 톤수 | 표 추세 연장 | 최저임금 반영(+20%) |
| --- | --- | --- |
| 5톤 | 102만 | **122만** |
| 6톤 | 119만 | **143만** |
| 7톤 | 151만 | **181만** |

### 3) 서비스 적용

산출값을 실제 이사 플랫폼(아정당) 공개 가격표와 비교해 시장 가격 범위와 크게 다르지 않음을 확인했다.
다만 실제 서비스는 **1 / 2.5 / 5 / 7.5 / 10톤** 단위와 인력 구성별 가격을 쓴다. 그래서 위 [기본요금 표](#기본요금-base_pricecsv)도 그 구조를 따랐다.

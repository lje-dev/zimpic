# 05. 가구 데이터

출처: `ML_DL 3조 프로젝트.xlsx` — 가구 데이터, 가구 회전 데이터 시트. 현재 값: `backend/policy/data/furniture.csv`, `furniture_rotation.csv`
테이블 구조는 [07. DB 스키마](07-db-schema.md#furniture) 참고.

## 기준 사이즈 정하는 방법

- 클래스마다 **대표 실제 제품 1개**를 정하고 그 제품 치수를 기본 W/D/H로 사용한다 (가전 = LG, 가구 = 이케아 위주).
- 클래스 경계는 `description`에 사용자 문구로 적는다. 예: "1인용을 제외한 2인 이상 소파는 모두 대형 소파로 계산했어요."
- 사용자는 AI 결과 화면에서 사이즈를 직접 수정할 수 있다.
- 접이식(러닝머신, 실내자전거)은 **접었을 때** 크기 기준.
- 시스템 행거는 분해 포장 묶음 1개를 1블록으로 보고, 사용자가 확인한 블록 수를 부피와 분해/재조립 비용의 기준으로 사용한다.
- 에어컨 실외기, 이사 박스는 YOLO 클래스가 없는(`yolo_id = null`) 보조 항목이다. 실외기는 에어컨 선택 시 자동 추가되고, 박스는 평수 기준으로 개수를 산정한다.

## 포장재 두께 (padding_cm)

가구별 `padding_cm`을 좌우·앞뒤·위아래에 적용해 포장 후 적재 크기를 만든다.

```text
packed_w = width_cm  + padding_cm × 2
packed_d = depth_cm  + padding_cm × 2
packed_h = height_cm + padding_cm × 2
packed_cbm = packed_w × packed_d × packed_h ÷ 1,000,000
```

CBM 증가율 = `(W+2t)(D+2t)(H+2t) / (W·D·H)`

- 부피, 차량 경계, 물건 간 충돌, 회전, 적층 높이는 모두 포장 후 치수를 기준으로 계산한다.
- padding이 각 방향에 이미 포함되므로 물건 사이에 같은 여유를 다시 더하지 않는다.
- 3D 화면에서 원래 가구 크기와 padding 영역을 구분해 표현할 수 있지만, 충돌 판정은 padding을 포함한 바깥 크기를 사용한다.

| padding_cm | 포장 형태 | 예시 | 대표 예시의 CBM 증가율 |
| --- | --- | --- | --- |
| 0.5 | 얇은 에어캡 + 테이핑 정도의 최소 포장 | 금고 | 약 1.07 |
| 1.0 | 담요, 커버 등 일반 포장 | 침대, 책장 | 약 1.08 |
| 2.0 | 5T 에어캡 3~4겹, 일반 가전 안전 포장 | 세탁기, 냉장고 | 약 1.14 |
| 3.0 | 에어캡 여러 겹 + 코너 보강대 / 앞뒤 면 보강 | 모니터, 어항 | 약 2.21 ※ |

※ 증가율은 물건의 원래 치수에 따라 달라진다. 3.0cm 예시는 두께가 얇은 TV(73×5×43)를 기준으로 약 2.21배이며, 같은 padding이라도 크고 두꺼운 물건의 증가율은 더 낮다.

## 적층 규칙

두 물건을 쌓으려면 다음 조건을 모두 만족해야 한다.

1. 위 물건의 `stackable`이 `true`다.
2. 아래 물건의 `can_stack_on_top`이 `true`다.
3. 위 물건의 포장 후 바닥면이 아래 물건의 포장 후 지지면 안에 들어간다.
4. 포장 후 높이의 합이 차량 내부 높이를 넘지 않는다.
5. 두 물건이 차량 경계나 다른 적재물과 겹치지 않는다.

- 이사 박스는 위 조건을 지키는 범위에서 여러 층으로 쌓을 수 있다.
- TV, 어항, 피아노, 금고 등 파손 또는 중량 위험 품목은 적층하지 않는다.
- 분해·조립 서비스 선택은 추가 작업비에만 반영하며 포장 후 치수와 차량 산정 부피는 변경하지 않는다.
- 피아노, 금고, 돌침대 등 중량 품목은 특수가구 추가요금으로 처리한다. 차량 추천은 부피와 형상을 기준으로 하며 실제 중량은 반영하지 않는다.

## 회전 코드 (orientation_code)

코드 = 적재 시 (X축, Y축, Z축=높이)에 오는 포장 후 치수.

| 코드 | 축 | 상태 |
| --- | --- | --- |
| WDH | X=W, Y=D, Z=H | 기본 배치. 원래 사용하는 방향 그대로 (냉장고, 책장, 세탁기) |
| DWH | X=D, Y=W, Z=H | 높이 그대로, 바닥에서 90° 회전 |
| WHD | X=W, Y=H, Z=D | 앞/뒤로 넘어뜨린 상태 |
| HWD | X=H, Y=W, Z=D | 매트리스·판형 가구를 길이 방향으로 세움 |
| DHW | X=D, Y=H, Z=W | 좌우 측면으로 눕힘 (소파·매트리스) |
| HDW | X=H, Y=D, Z=W | 매트리스를 두께×길이로 세움 (안정형) |

가구 목록의 회전 표기:

| 표기 | 허용 코드 |
| --- | --- |
| 기본 | WDH, DWH (세운 그대로, 바닥 90° 회전만) |
| 4방향 | WDH, DWH, WHD, HWD |
| 눕힘 | DHW, HDW (옆으로 눕혀 적재) |
| 기본+눕힘 | WDH, DWH, DHW, HDW |
| 전체 | 6방향 모두 |

## 1. 방 정보 입력

### 이사 정보
- **이사 유형 선택**: [일반 이사] / [포장 이사] 중 하나만 선택
- **일반 이사 범위**: 고객이 이삿짐의 포장과 정리를 담당하고, 업체는 차량 운전·운반과 도착지에서의 지정 위치 배치만 담당한다.
- **포장 이사 범위**: 업체가 이삿짐 포장부터 운반, 도착지 배치와 정리까지 담당한다.
- **일반 이사 제한**: 일반 이사를 선택했더라도 산정된 차량 합계가 5톤 이상이면 포장이사로 자동 전환하여 계산한다.
- **평수 선택**: Range 슬라이더, 5~50평, 1평 단위, 기본값 10평

### 공간 관리
- **기본 공간**: 진입 시 공간 입력 영역 1개 제공 (삭제 가능)
- **공간 추가**: [+ 공간 추가하기] 버튼
- **공간 유형**: 드롭다운 — 거실 / 주방 / 베란다 / 다용도실 / 방
- **중복 제한**: 방을 제외한 공간 유형은 한 번만 추가 가능, 이미 추가된 유형은 disabled
- **방 개수 제한**: 최대 5개. 초과 시 안내 — *"방은 최대 5개까지 추가할 수 있어요."*
- **공간 삭제**: [삭제하기] 버튼, 업로드한 이미지도 함께 삭제
- **공간 없음**: *"공간 추가하기 버튼을 눌러 공간을 먼저 추가해 주세요"*

### 이미지 업로드
- 공간당 대표 이미지 1장
- 파일 선택 또는 Drag & Drop
- 촬영 가이드: 공간의 모든 짐이 한 장에 보이도록. 일부만 찍히면 정확한 견적이 어렵다는 안내

### 페이지 이동
- 이사 유형 + 평수 + 최소 1개 공간 이미지 업로드 완료 시 [다음] 활성화
- [다음] → 이미지 분석 결과 화면

## 2. 이미지 분석 결과

### 공간 카드
- 업로드한 공간 단위로 분석 이미지 + 가구 목록 표시
- 분석 중에는 스피너/스켈레톤 + *"이미지를 분석중이에요"*
- 분석 완료 이미지에 탐지 가구를 bbox로 표시

### 가구 목록
- 가구명, 수량, 사이즈 표시
- **체크박스**로 이삿짐 포함 여부 선택 (기본 체크). 해제 시 계산 제외 + 입력 영역 비활성화
- **사이즈 자동 입력**: W/D/H는 DB 기본값, 사용자 수정 가능
- **수량 수정**: 일반 가구는 수량을 직접 수정하지 않고 동일 가구를 추가하는 방식으로 처리한다. 시스템 행거만 예외적으로 `블록 수`를 직접 수정할 수 있으며 기본값은 1이다.
- **시스템 행거**: 사이즈 입력 대신 블록 수와 분해/재조립 필요 여부를 입력한다. AI가 정확한 블록 수를 판별하기 어려우므로 사용자가 사진과 실제 설치 상태를 보고 확인·수정한다.
- **에어컨**: 선택 시 실외기 자동 추가
- **가구 직접 추가**: DB에 등록된 가구를 select로 선택 → [추가하기]. 직접 추가한 가구는 삭제 가능

### 페이지 이동
- [이전] → 방 정보 입력 (입력값 유지)
- [다음] → 주소 입력

## 3. 주소 입력

### 출발지
- 주소 검색: 카카오(다음) 우편번호 서비스, 도로명 주소까지 입력
- 층수 입력
- 엘리베이터 유무 체크박스 (기본: 있음)
- 사다리차 필요 여부 체크박스 (기본: 미체크)

### 도착지
- **도착지 미정** 체크박스: 체크 시 *"아직 이사갈 집이 정해지지 않았어요(도착지 미정)"*, 도착지 입력 영역 비활성화
- 미정 해제 시 출발지와 동일한 항목 입력 (주소, 층수, 엘리베이터, 사다리차)

### 검증
- 도착지 미정 해제 + 주소 미입력 → [견적 보기] 시 이동 불가, 안내 노출
- 필수 입력값 미충족 시 [견적 보기] 비활성화 또는 이동 불가

### 페이지 이동
- [이전] → 이미지 분석 결과 (입력값 유지)
- [견적 보기] → 견적 결과

## 4. 견적 결과

| 영역 | 내용 |
| --- | --- |
| 예상 이사 비용 | 상단에 단일 예상금액. 하단에 이사 유형 / 트럭 정보 / 이사 날짜(요일) 요약 |
| 선택 정보 | 이사 유형, 평수(`N평`), 출발지·도착지 층수와 엘리베이터 유무, 예상 거리(km), 사다리차 사용 여부, 특수 이삿짐 `총 N개` |
| 이삿짐 정보 | 방 단위 카드/리스트 — 방 번호, 대표 이미지, 이삿짐 이름·수량, 크기 기준(예: `300×200×100 기준`), 평균 박스 수와 최소~최대 참고 범위 |
| 예상 이사 차량 | 포장 후 치수로 3D 적재가 가능한 차량 종류와 대수 |
| 3D 적재 시뮬레이션 | 추천 차량을 산정할 때 사용한 배치 결과를 동일한 좌표와 회전 방향으로 표시 |
| 견적 세부 내역 | 기본 이사 비용(톤수·작업자 수), 사다리차 비용(출발/도착 분리), 특수 이삿짐 비용(항목별), 추가 비용은 `+ 금액` |
| 총 예상 비용 | 모든 비용 합산, 강조 표시 |
| 저장하기 | 견적 결과 화면을 PDF로 저장 |

- 결과 금액은 확정 금액이 아닌 **예상 견적**으로 표시한다.
- 일반 이사를 선택했지만 산정 물량이 5톤 이상이면 포장이사 요금을 적용하고, 결과 화면에 물량에 따라 포장이사로 전환되었음을 안내한다.
- 주말·성수기·손 없는 날과 실제 현장 조건에 따라 추가금이 발생할 수 있음을 안내한다.
- 도착지 미정 시 거리비와 도착지 작업비가 제외된 **출발지 조건 기준 최소 예상금액**으로 표시한다.
- 10톤 초과 물량은 10톤 기준 예상금액을 표시하고, 정확한 금액은 전화상담이 필요하다고 안내한다.
- 3D 화면에는 *"실제 작업 환경과 다를 수 있는 예상 적재 시뮬레이션입니다."*라는 안내를 표시한다.
- [이전] → 주소 입력 (입력값 유지)
- 새로고침 시 견적 결과 초기화 후 방 정보 입력 화면으로 이동
